# Forschungs- und Spike-Berichte

Ergebnisse zeitlich begrenzter Spikes (Skill `/spike`), Dateiname `S-<ID>-<kurz>.md`. Ein Bericht enthält: Frage,
Methode, Ergebnisse (bestätigt / wahrscheinlich / Vermutung), Empfehlung, neue Risiken und Folge-WPs. Offene Spikes
stehen in der [Roadmap](../ROADMAP.md#spikes-vor-den-abhängigen-meilensteinen).
